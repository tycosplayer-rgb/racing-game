# 霓虹狂飙 · Racing Game

竖屏优先的 **触屏霓虹赛车** 小游戏：在夜间公路上躲避对手与障碍，冲得越远得分越高。

## 在线游玩

**https://tycosplayer-rgb.github.io/racing-game/**

手机竖屏即可；大按钮触控，支持多指同时按。

## 本地运行

直接打开：

```bash
open index.html
# 或双击 index.html
```

或用本地静态服务：

```bash
npx --yes serve .
# 然后打开提示的地址
```

无需构建步骤（纯静态 HTML / CSS / JS）。

## 操作说明

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 左转 | ← 或 `A` | 左侧 ◀ |
| 右转 | → 或 `D` | 右侧 ▶ |
| 加速 | ↑ / `W` / 空格 | 中间「加速」 |
| 开始 / 再来一局 | Enter / 空格 | 叠加层按钮 |
| 结束后重开 | `R` | 叠加层按钮 |

## 玩法

1. 点击「开始游戏」进入赛道  
2. 左右转向避开对向/同向车辆与路障（油桶、三角锥）  
3. 按住加速可提速冲刺，但碰撞风险更高  
4. 速度会随距离逐渐提升，撞车即结束  
5. 以行驶距离（米）计分，最高纪录保存在本机浏览器  

## 技术
