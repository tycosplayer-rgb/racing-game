# 霓虹狂飙 · Racing Game

竖屏优先的 **触屏霓虹赛车** 小游戏：在夜间公路上躲避对手与障碍，冲得越远得分越高。

## 在线游玩

**https://tycosplayer-rgb.github.io/racing-game/**

手机竖屏即可；大按钮触控，支持多指同时按。

## 本地运行

直接打开：

```bash
open index.html
# 或双击 index.html
```

或用本地静态服务：

```bash
npx --yes serve .
# 然后打开提示的地址
```

无需构建步骤（纯静态 HTML / CSS / JS）。

## 操作说明

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 左转 | ← 或 `A` | 左侧 ◀，或在赛道上**左右拖动**（车子跟着手指移动） |
| 右转 | → 或 `D` | 右侧 ▶，同上 |
| 加速 | ↑ / `W` / 空格 | 中间「加速」 |
| 开始 / 再来一局 | Enter / 空格 | 叠加层按钮 |
| 结束后重开 | `R` | 叠加层按钮 |
| 静音 / 开音效 | — | 右上角「静音」/「音效」 |

## 玩法

1. 点击「开始游戏」进入赛道  
2. 在赛道区域**左右拖动手指**，车子会直接跟着左右移动；也可用 ◀▶ 按钮或键盘  
3. 按住加速可提速冲刺，但碰撞风险更高  
4. 速度会随距离逐渐提升，撞车即结束  
5. 以行驶距离（米）计分，最高纪录保存在本机浏览器  
6. 每行驶 **500 m** 会有里程音效提示  

## 音效

- 使用 **Web Audio API** 实时合成（引擎声、转向、碰撞、开局/结束、里程、按钮点击），**无外部音频文件**  
- 浏览器要求用户手势后才能出声：首次触摸 / 点击 / 按键会解锁音频  
- **默认开启音效**；右上角按钮可切换  
  - 显示「静音」→ 当前有声，点按后静音  
  - 显示「音效」→ 当前静音，点按后开声  
- 静音偏好保存在 `localStorage`（键名 `neon-racing-muted`）
